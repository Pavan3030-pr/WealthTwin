# WealthTwin — Design System

Light theme only. Calm, trustworthy, modern finance aesthetic.

## Colour Tokens

- --background: #FAFAF9
- --surface: #FFFFFF
- --foreground: #1C1917
- --primary: #0D9488 (teal)
- --accent: #0EA5E9
- --success / --warning / --danger

No dark mode. No dark: classes.

## Components
Cards, Risk badges (green/amber/red), progress bars, tables.
